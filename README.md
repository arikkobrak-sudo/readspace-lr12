# ReadSpace (ЛР №11)

Адаптивний лендинг читацького клубу ReadSpace з інтегрованими динамічними медіакомпонентами на чистому JavaScript (Vanilla JS) через CDN.

## Інтегровані JS-бібліотеки (CDN)

- **Swiper.js v11** — інтерактивний адаптивний слайдер у секції відгуків (`#reviews`): 6 слайдів, нескінченний цикл (`loop`), автопрогортання (`autoplay`) із зупинкою при наведенні курсора (`pauseOnMouseEnter`), стрілки навігації, клікабельна пагінація та брейкпоінти (`1 / 2 / 3` слайди).
- **Fancybox v5** — модальна галерея видань та простору клубу (`#gallery`): групування в єдиний альбом (`data-fancybox="readspace-gallery"`), підписи (`data-caption`), ефект переходу `fade` та масштабування зображень (`Panzoom.maxScale: 3`).

## Інтерактивний віджет «Планувальник читання» (ЛР №11)

Секція `#planner`: користувач вводить кількість сторінок, хвилини читання на день, темп (20 / 30 / 45 сторінок за годину) і чи читає у вихідні. Віджет одразу показує, скільки сторінок читати щодня, кількість днів читання та дату останньої сторінки.

- `assets/js/widget.js` — ізольований модуль (IIFE) на чистому JavaScript: валідація та нормалізація даних, розрахунок, безпечний вивід через `textContent`, підтримка кількох екземплярів через `data-planner`.

## Структура проєкту

- `index.html` — головна сторінка лендингу з CDN-підключенням Swiper.js та Fancybox;
- `assets/css/widgets.css` — стилі для слайдера відгуків, запобігання FOUC до ініціалізації та сітки галереї;
- `assets/js/widgets.js` — ініціалізація Swiper.js та Fancybox усередині `DOMContentLoaded`;
- `assets/js/widget.js` — планувальник читання (ЛР №11);
- `assets/js/validation.js` — клієнтська валідація форми зворотного зв’язку;
- `assets/images/` — графічні активи ReadSpace (обкладинки, аватари, логотип).
